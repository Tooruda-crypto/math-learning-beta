# まいにち算数 Ver.0.1

小学1〜3年生向けの、毎日5〜10分で取り組む端末内保存型の算数学習アプリです。

## Ver.0.1の範囲

- 学年別のルールベース問題生成と4択回答
- 1回だけの再挑戦とルールベースのヒント
- 学習履歴・単元進捗・ポイント・学習日・街の端末内保存
- 兄弟それぞれに分離された複数プロフィール
- 学習履歴に応じた10問の個別最適化
- プロフィール別の途中セッション保存、ホーム復帰、再開
- 保護者向け学習状況画面
- 軽量なCSS・自作SVGによる宇宙テーマ（動きを減らす端末設定に対応）
- iPhone縦、iPad縦・横対応

クラウド、認証、AI API、課金、広告、オンライン機能は使用していません。データは`AppRepository`を経由してブラウザのIndexedDBだけに保存します。

保存形式は`schemaVersion: 4`です。Version 3以前の単一プロフィールデータは、初回読込時に既存プロフィールのIDへ履歴・進捗・ポイント・街・途中セッションをまとめて紐付けます。プロフィールを追加した後は、これらの学習データをプロフィールID単位で分離して保存します。

## 開発コマンド

```sh
npm install
npm run dev
npm run lint
npm test
npm run build
```

## 実利用テストを初期状態から始める

一般画面にはデータ削除ボタンを設けていません。開発中の試用では、次のいずれかで既存データと分離してください。

1. 推奨：新しいブラウザプロファイル、プライベートウインドウ、または未使用の端末で開く。
2. 開発者ツールを使う場合：対象のローカル開発URLを開き、Application（ストレージ）→ IndexedDB → `sansu-learning-app` → `Delete database`を実行してから再読込する。

削除操作は、その開発URLに保存されたプロフィール、履歴、進捗、ポイント、街、途中セッションをすべて消します。実利用中の端末では行わないでください。本番buildに開発用リセットUIや削除処理は含まれません。

## 子ども向け実利用テストの記録項目

- 初回設定を迷わず完了できたか
- 「だれが勉強する？」で自分のプロフィールを迷わず選べたか
- 「今日の算数をはじめる」を自分で見つけられたか
- 4択、ヒント、再挑戦の意味が伝わったか
- 問題中の「ホーム」と「つづきから」を自然に使えたか
- 10問を負担なく完走できたか
- 結果、ポイント、街の変化を理解できたか
- 中断後に「つづきから」を見つけられたか
- 誤タップ、読みにくい文字、押しにくいボタンがなかったか

ニックネームなど個人を特定できる情報は記録せず、学年、利用端末、所要時間、迷った箇所だけをメモしてください。
